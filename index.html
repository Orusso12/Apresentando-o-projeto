{} 01 — reflexão

O que pode virar objeto em uma conversa?

Antes de programar, o desafio é observar um aplicativo do dia a dia e decidir quais informações fazem sentido juntas. No WhatsApp, três exemplos ajudam a enxergar essa lógica.

ObjetoUm conjunto de informações e ações organizadas para representar algo.

02 — laboratório · teste os objetos

Execute o objeto e veja o que ele sabe fazer.

O objeto mensagem reúne quatro propriedades e um método. Clique em rodar para conferir o resultado no terminal.

mensagem.js 
const mensagem = {
  remetente: "Luiz",
  texto: "Oi! Como vai?",
  horaEnvio: "15:30",
  lida: false,
  exibirStatus() {
    return this.lida ? "Mensagem lida" : "Mensagem entregue";
  },
};
contato.js 
const contato = {
  nome: "Fernanda Mascheti",
  online: true,
  apresentar() {
    return this.nome + " está online agora";
  },
};

Interaja: marque a mensagem como lida

Alterar uma propriedade muda o comportamento do método exibirStatus().

mensagem.lida = false → "Mensagem entregue"
