Como o projeto foi construído

Estrutura

index.html

Define o esqueleto do quiz, organizando as seções de boas-vindas, perguntas e resultados em containers semânticos.

<section id="quiz">
  <h2 id="question"></h2>
</section>

Estilo

style.css

Implementa a identidade visual responsiva, utilizando variáveis para cores e transições suaves para o feedback do usuário.

:root {
  --green-500: #16b364;
  --lime: #d7f542;
}

Lógica

questions.js & script.js

Utiliza módulos ES6 para separar o banco de perguntas da lógica de controle, garantindo um código limpo e fácil de manter.

import { questionBank }
from './questions.js';
questionBank.map(...);
