# Apresentação — Missão Futebol

Apresentação final do projeto de quiz interativo desenvolvido no curso de Técnicas Computacionais da Alura.

## Conteúdo

A apresentação contém 7 slides em HTML:

1. Capa — Missão Futebol
2. Do conteúdo à experiência
3. A jornada do usuário
4. Como o projeto foi construído
5. Momento de interação
6. O que aprendemos
7. Impacto: aprender jogando

## Como visualizar

Abra qualquer arquivo `.html` em um navegador moderno. Para navegar pela sequência, abra os arquivos na ordem indicada acima.

Os slides usam fontes do Google Fonts e ícones do Font Awesome via CDN.
